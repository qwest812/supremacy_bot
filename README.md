# supermessy_bot — бот для Supremacy 1914

Бот сам ведёт партию: строит, призывает войска, торгует, обороняется
и воюет с ботами. Каждое решение он объясняет в журнале. Карта — «Европа»,
скорость x4, одна партия за раз.

## Запуск

```bash
cp .env.example .env      # впишите S1914_USER и S1914_PASSWORD
go run ./cmd/bot -games   # ваши идущие партии
go run ./cmd/bot -lobby   # открытые партии «Europe» x4
go run ./cmd/bot -paper N # потери по газете партии N (только чтение)
go run ./cmd/bot -once    # один заход и выход
go run ./cmd/bot          # играть, пока не остановят (Ctrl+C)
```

По умолчанию `DRY_RUN=true`: бот заходит в партию и пишет в журнал, что
сделал бы, но в игру ничего не отправляет. Когда решения в журнале вас
устроят, поставьте `DRY_RUN=false`.

Партия берётся из `GAME_ID`. Если он пустой, бот выбирает единственную
вашу идущую партию под фильтр `LOBBY_TITLE`/`LOBBY_SPEED`. В новую партию
бот пока не вступает сам: вступите в игре и дайте ему номер.

Проверить правила без игры, по сохранённому ответу игрового сервера:

```bash
go run ./cmd/bot -state internal/s1914/testdata/state_x4_day2.json \
  -map internal/s1914/testdata/map_51_5.json -me 6
```

## Интерфейс и карта

Бот поднимает веб-интерфейс вместе с собой: http://127.0.0.1:8090
(адрес задаётся `UI_ADDR`, пустое значение его выключает).

```bash
go run ./cmd/bot -ui     # только интерфейс к уже записанным журналам
go run ./cmd/bot -demo   # демо по записанной партии (3 захода) и интерфейс
```

- **Карта** заходов. Провинции раскрашены по владельцам: наши обведены
  жёлтым, враги красным, цель войны заштрихована, провинции под угрозой
  обведены оранжевым пунктиром. Кружки — армии (размер по силе): синие
  наши, красные вражеские, серые прочие. Стрелки — приказы бота: красные
  атаки и захваты, оранжевые оборона и подкрепления, серые пунктирные
  отступления. Квадратики — стройка (зелёный) и войска (коричневый).
  Колесо мыши — масштаб, перетаскивание — сдвиг, ⌂ — к нашей стране.
- **Ползунок заходов** листает партию. ▶▶ проигрывает заходы подряд,
  ← и → на клавиатуре работают так же. С включённым «следить» новые
  заходы подтягиваются сами.
- **Решения** выбранного захода с фильтром по категориям и поиском.
  Наведение подсвечивает провинцию и стрелку на карте, клик ведёт к ней.
- **Сводка**: графики территории, силы армий, денег и сырья по заходам.
- **Провинция** (клик по карте): владелец, ресурс, здания, армии,
  решения этого захода и история решений по ней.

Ссылка запоминает вид (`#visit=3&p=488&tab=summary`), ею можно поделиться.

## Журналы

`logs/<номер партии>/`:

| файл | что в нём |
|---|---|
| `all.log` | всё по порядку: шапка захода (день, запасы), каждое решение, итог и когда следующий заход |
| `build.log` | стройка зданий |
| `recruit.log` | войска: бронеавтомобили, казармы по еде, сколько прибавилось пехоты |
| `attack.log` | объявление войны, захваты провинций, атаки |
| `defense.log` | угрозы, подкрепления, удары по армиям у границы, отступления |
| `market.log` | торговля с ботами и биржа, итоги сделок |
| `diplomacy.log` | право прохода и прочие отношения |
| `decisions.jsonl` | заходы, решения и итоги в JSON, их читает интерфейс |
| `snapshots/<заход>.json` | партия на миг захода: владельцы, армии, приказы с путями |
| `map.json` | очертания провинций для карты |

Строка решения выглядит так:

```
2026-10-24 22:31:05 | день 2 | СТРОЙКА    | СДЕЛАНО  | [казарма-в-дабл] Тронхейм: Казармы — двойная провинция: казарма ускоряет призыв; цена: Зерно 1 500, Дерево 1 500, Деньги 4 000
```

Отметка: `ПЛАН` в режиме DRY_RUN, `СДЕЛАНО`, `ОТКАЗ ИГРЫ: …` или `заметка`.
Заметка — это решение ничего не делать, с причиной («не хватает руды,
накопится к 23:32»). Одинаковая заметка два захода подряд пишется один раз.

## Правила (этап 2)

Пороги задаются в `.env`, логика лежит в `internal/bot`:

- **Стройка** (`economy.go`): пункт призыва во всех провинциях; мастерская
  и казарма в провинциях с двойными ресурсами (казарма ещё и в столице);
  со 2-го дня порт в прибрежных двойных; с 3-го железная дорога, если
  хватает ресурсов (двойные и столица, с запасом денег); с 5-го дня
  ресурсы откладываются на фабрику, на 6-й она ставится в столице.
- **Войска** (`recruit.go`): в каждой провинции со свободным слотом бот
  заказывает из того, что игра там разрешает (`UNITS`: бронеавтомобиль,
  кавалерия, штурмовики, танки), войско с наибольшей силой на единицу цены.
  Цена — по справочным ценам биржи, ресурс в дефиците считается вдвое
  дороже: в начале партии, когда мало руды и нефти, это обычно кавалерия.
  Казарма работает, только пока в её провинции производится кавалерия
  или штурмовики; иначе бот ставит её на паузу, чтобы не ела зерно.
  Пехоту игра призывает сама, бот её считает.
- **Рынок** (`market.go`):
  1. *Дефицит.* Бот смотрит, чего не хватило стройке, что с отрицательным
     приростом кончится за `TRADE_FORECAST_DAYS` суток и что скоро станет
     редким на всей карте. В начале партии это руда и дерево, с
     `TRADE_OIL_FROM_DAY` — нефть. Их он держит не меньше
     `TRADE_STRATEGIC_STOCK`.
  2. *Биржа — только покупка.* Нужное сейчас бот берёт не дороже справочной
     цены ×1.2, впрок — только не дороже справочной (`TRADE_CHEAP_MARKUP`).
  3. *Обмен.* Чего не купил, просит у живых игроков
     (`TRADE_WITH_HUMANS`) в обмен на свой излишек. Считает по справочным
     ценам и даёт переплату ×1.1, чтобы обмен приняли. Дефицитное в обмен
     не отдаёт. Ботам прямых сделок не предлагает: они их не принимают.
  4. *Продажа за деньги* — живым игрокам по `TRADE_RATE` за единицу
     и только излишек сверх `TRADE_KEEP_STOCK + TRADE_SELL_ABOVE`. На бирже
     бот не продаёт: там теряется 20%.

  Предложения от других бот принимает, если они выгодны по справочным
  ценам или дают дефицитный ресурс не в убыток. Тем, кто отказался, этот
  ресурс сутки не предлагает.
- **Дипломатия** (`diplomacy.go`): всем ботам право прохода, кроме тех,
  с кем воюем.

## Война (этапы 3–5)

Логика лежит в `military.go`, пороги задаются в `.env` (раздел «Война»).
Сила армии считается по оценке самой игры: пехотинец 4.5,
бронеавтомобиль 9, кавалерия 11.25. Крепость каждого уровня прибавляет
обороне четверть.

- **Оборона** работает всегда. Угроза — это вражеская армия в нашей
  провинции или в соседней. Сначала угрозы внутри, потом у самых ценных
  провинций (столица, дабл ресы, очки победы). Если свободных сил вокруг
  хватает с перевесом ×1.5, бот бьёт первым. Если нет, подтягивает
  подкрепления до 1.2 от силы врага. Если провинцию не удержать и враг
  сильнее всего, что можно собрать, в 2.5 раза, гарнизон уходит
  в безопасную провинцию. Столицу бот не бросает никогда.
- **Газета** (`intel.go`): каждый заход бот читает газету партии
  наблюдателем и считает, кто сколько потерял в войнах. Газета считает
  солдат, юнит — это 1000 солдат. На стандартной карте на старте в каждой
  провинции 10 пехоты (`START_GARRISON`), поэтому стартовая армия страны
  равна числу её провинций при первом заходе бота × 10. Если бот пришёл
  в партию не с первого дня, оценка приблизительная, и журнал об этом
  пишет. Посмотреть газету любой партии: `go run ./cmd/bot -paper <номер>`.
- **Объявление войны**: одна война за раз. Если с соседом уже воюем,
  продолжаем с ним. Иначе с 3-го дня, когда угроз нет, а свободных сил
  хотя бы 60, бот выбирает бота-соседа с лучшим соотношением «ценность
  пограничных провинций / их видимая оборона» и объявляет ему войну.
  Сосед, потерявший по газете `WAR_WEAK_SHARE` (30%) стартовой армии
  и больше, — цель и до 3-го дня, а его оценка как цели растёт
  в 1 + `WAR_WEAK_BONUS` × доля потерь раз: резервов за его границей нет.
  Людям сам войну не объявляет (`WAR_ON_HUMANS=false`). Мирный период
  и период чести соблюдаются.
- **Захват**: вражеские провинции у нашей границы, по ценности на единицу
  обороны, до 3 за заход. Пустую берёт одна ближайшая слабая армия,
  занятую — ближайшие армии с перевесом ×1.5 (атакой на армию гарнизона).
  Последнюю армию столицы в наступление не берём.
- **Стаки** (`WAR_STACKS`): армии, пришедшие в одну точку, игра сливает
  в одну (кроме армий с героями). Большой стак теряет меньше и бьёт
  сильнее. Если на цель нужно несколько армий из разных мест, бот сначала
  сводит их в нашу провинцию рядом с целью, где наших сил уже больше всего,
  и ждёт, пока все дойдут. Бьёт он уже оттуда, одной армией. Армия,
  которой сил хватает одной, идёт сразу.

«Свободная» армия — сухопутная, на суше, не в бою, без приказа марша
и не стоящая там, где самой угрожают. Пути прокладываются по дорогам:
через свои земли, через земли тех, кто дал нам право прохода, и через
земли врага. В чужие мирные земли бот не заходит.

Порядок, в котором правила получают ресурсы, задан в `planner.go`.

## Что проверено в живой игре

Формат приказов снят с браузерного клиента игры. Часть из них уже
работает в `vendetta_admin`, остальные собраны по коду клиента и ждут
первой проверки:

| приказ | статус |
|---|---|
| вход, состояние партии, стройка, заказ войск, марш армии, право прохода | проверено (vendetta_admin) |
| газета: потери в войнах | проверено, чтение (vendetta_admin и `-paper 10937470`, 30.10.2026) |
| включить или выключить здание, сделка с игроком, сделка на бирже, атака армии, объявление войны | по коду клиента, **ждёт проверки** |

## Устройство

- `internal/s1914` — клиент игры: вход на сайт, игровой сервер, разбор
  состояния (провинции, армии, рынок, сила юнитов), карта и пути, приказы.
  Перенесён из `vendetta_admin` и дополнен.
- `internal/bot` — решения (`Decide`), журналы, память партии, цикл заходов.
- `internal/ui` — веб-интерфейс: сервер и страница (`static/`), вшиты в бинарник.
- `cmd/bot` — запуск и настройки.
